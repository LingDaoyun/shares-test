## 改变的行为

- 原“潜力龙头”导航改为“五日观察”，兼容原入口并新增 `#/five-day`；独立短线右侧保留。
- 先在当前板块范围逐股核对连续25个精确市场交易日；完整有效缓存直接复用，缺日或OHLCV无效才通过现有历史接口整窗回补。完整新窗口整体保存，价格预选和量价计算使用同一份日线，再按连续主力净流入区分资金增强候选、量价对照和资金缺失。
- 最多8个在途回补任务，保留现有供应商节流；扫描消息逐只显示“补齐/检查连续日线 x/n”。回补后仍缺失的股票独立计数和披露，不当作价格不合格。
- 采用 `five-day-observation-v1` 固定参数和稳定预选次序，最多复核 100 只；页面披露参数、证据与未复核覆盖。
- 以买入日为第 1 天，第 5 个市场交易日为计划退出日，分别保留固定计划与风险退出的情景结果。
- 新增不可覆盖的前瞻观察快照；真实交易仍沿用用户填写的成交账本，不自动下单。

## 运行依赖

后端依赖原有收盘基线、日 K 数据、现有历史日线接口、东方财富日级资金接口与成交额/换手补齐。第一次扫描可能先触发基线准备，再按需回补当前范围的连续25日日线；已有较多旧日线不代表中间交易日完整。此路径不修改旧基线的15根门槛，也不改变五日策略阈值。读取扫描状态不重复调用行情接口；重新扫描通过 POST 明确启动。

Flyway 新迁移 `apps/api/src/main/resources/db/migration/V5__five_day_observation.sql` 只新增 `five_day_scan` 表。空库迁移、重复执行幂等及V4升V5保留原数据已在独立测试库通过；本机部署与最终真实扫描结果单独记录。前端发布仍需更新实际构建产物，单改源码不会改变现有运行页面。

默认主板收盘扫描由服务运行时的定时器触发，已经固化的同日同范围快照不重写。原龙头学习定时器默认禁用；旧接口和历史表保留。当前交易日历只覆盖 2026 年。

## 用户验收情景

- [ ] 新旧三个页面入口均显示五日观察；独立短线右侧仍可进入。
- [ ] 默认主板；创业板、科创板范围有独立快照。切换范围或刷新时旧请求结果不串入新范围。
- [ ] 市场交易日 15:40 前使用上一交易日，之后使用当日；周末、节假日使用最近市场交易日。
- [ ] 基线准备中、正在扫描、失败、成功状态均可区分；仅扫描中轮询读取状态，失败后可手动重试。
- [ ] 量价筛选要求 25 个连续市场交易日。缺少成交额或换手时标缺，不补零、不用更早日线替代。
- [ ] 中间交易日缺失或OHLCV无效时，按所需25日范围整窗回补；完整窗口不重复获取历史价格，旧基线日线不覆盖新的预选依据。
- [ ] 回补最多8个任务在途，显示“补齐/检查连续日线 x/n”；供应商节流保持原值。
- [ ] 无法补齐的日线计入缺失并显示示例；空候选且仍有数据缺失时显示失败及覆盖说明，可以重扫，不保存为空候选成功快照。有实际候选时保留候选并披露其他股票缺口。
- [ ] 资金累计值只取信号日及此前 4 个市场交易日；过时、未来、冲突数据不能凑足 5 日。累计资金占比使用累计额相除。
- [ ] 全部量价候选缺资金时仍可查看和重扫，但不进入前瞻统计；部分缺失则在首次成功快照中保留缺口。
- [ ] 最多复核 100 只，未复核数量明确；同样的价格数据与范围具有稳定次序。
- [ ] 2026-09-08 实际买入：当日计第 1 天，2026-09-14 为第 5 天。2026-09-24 买入跨中秋及国庆，计划退出为 2026-10-08。
- [ ] 超过入场上限、开盘不高于失效位、涨停附近买入或零量不能假设入场；错过唯一入场日不换日追买。
- [ ] 2026 年底跨入未核实年度时明确日历缺失，不把工作日直接当市场交易日。
- [ ] 日线缺失与明确不可成交分别处理；原计划日缺日线不顺延到第 5 根有效 K 线；明确延期退出显示真实情景退出日。
- [ ] 收盘跌破失效位后，风险模型最早按下一交易日可卖出的开盘价计算，遵守 T+1，不按失效位虚构成交。
- [ ] 买入屏蔽涨停附近，卖出屏蔽跌停附近；这些只是日线情景门槛，不是撮合成交保证。
- [ ] 同一前复权序列变基后，用信号日锚点缩放失效位和入场上限；缺少锚点时收益留空。
- [ ] 固定与风险模型独立完成、独立计算均值，扣除 0.20% 往返成本假设；没有成交或缺数据的结果不记作 0%。
- [ ] 快照生成和保存晚于唯一入场日 09:15 时标记非前瞻，显示历史研究但不进入前瞻统计。
- [ ] 同日同版本同范围成功快照不能覆盖；历史跨范围重复股票按最早前瞻观察去重，资金缺失不进入对照或增强均值。
- [ ] 历史刷新只使用本地日 K，读取页面不发起供应商请求；没有后续数据时保留待数据状态。
- [ ] 用户点击加入复盘才创建来源 FIVE_DAY 的记录；录入真实买入后计算计划，没有买入不虚构持仓。录入平仓后显示已平仓。
- [ ] FIVE_DAY 不暴露旧推荐价 T1/T5/T20 收益，也不参与旧 T20 学习统计；实际成交毛收益保留并注明费用未入账。

## 研究结论边界

主力净流入与换手增加只能组成待检验的信号，不能单独证明吸筹或待涨。现有文献不能证明这组具体阈值在 A 股五日持有上有稳定、扣费后的优势。参数、成本、100 只覆盖上限与入场门槛均需以之后保存的真实时点样本评估；更改参数应另立版本，不能覆盖旧样本。

两组是包含关系，跨日期股票可能重复，统计不是独立随机实验，也未建模组合资金占用。日 K 推算的可成交性不是券商成交回执。5% 初始价差上限不是亏损保证，20 bps 也不能代替真实费用账单。实际执行效果以用户成交账本为准。
