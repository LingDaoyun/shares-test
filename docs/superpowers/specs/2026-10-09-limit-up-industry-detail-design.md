# 涨停行业三级详情设计

用户需求：涨停看板的行业聚合中，点击某行业的涨停家数，打开三级详情，查看具体涨停股票及行业内上涨但尚未涨停的股票。

已确认展示范围：涨停股票全部展示；未涨停的上涨股票按涨幅降序，最多展示 30 家。用户于 2026-10-09 确认实施、定向回归、前后端部署与单独提交。

## 页面与交互

- 复用现有 `DetailOverlay`，从涨停看板详情内打开行业详情层，保留原看板及其日期。
- 行业卡片的涨停家数改为可点击按钮，支持键盘操作。
- 页头展示行业、数据日期、涨停家数，并提供“返回涨停看板”。
- 第一组显示全部涨停股：名称、代码、涨幅、现价、连板高度、首次封板时间、成交额。
- 第二组显示上涨但未涨停股票：按涨幅降序，展示名称、代码、涨幅、现价、成交额及换手率；标明最多 30 家。
- 提供加载、重试、空列表状态。行业行情不可用时保留已有涨停明细，并明确未涨停股票暂缺。

## 数据

- 新增行业详情接口，接受行业名称及看板的交易日期。
- 涨停家数与明细来自同一个涨停池快照，按行业过滤，不另行估算涨停数量。
- 未涨停列表使用行业成分行情，按涨幅读取并分页；排除涨停池中的证券及非上涨、无有效价格或日期不匹配的行情，再排序和限制展示数量。
- 不把抓取时间替代交易日期，也不把最新行情拼进其他日期的涨停快照。
- 不增加选股或交易执行规则，不扩展为新的行业数据源体系。

## 交付与验证

- 定向回归覆盖行业点击、返回、日期传递、两类股票不重复、排序及 30 家限制、行情失败时保留涨停明细。
- 同时构建、更新 API 与 Web，保留当前镜像作为回滚材料。
- 本功能单独提交，工作区既有五日观察与筹码改动继续保留。
