# 短线结果区横版展示与记忆型模块开关设计

## 1. 目标

短线模块在扫描完成后，需要把结果区从“长内容垂直堆叠”改成“可控展示 + 横版摘要”。

具体目标：

- 方法、市场情绪、今日资金去向、扫描快照、热门方向都可以单独勾选显示或隐藏；
- 默认隐藏“方法”和“今日资金去向”；
- 其他模块默认展示；
- 勾选状态在本机浏览器内记住，刷新和重启页面后仍然生效；
- 扫描快照、市场情绪、热门方向改成横版摘要展示，降低纵向占屏；
- 不修改短线扫描结果的数据含义，不改后端接口，不改推荐排序逻辑。

## 2. 当前问题

现在短线页在结果返回后直接把多个模块纵向铺开：

- “方法”总是占固定空间，但它更像解释说明，不是每次都要看；
- “今日资金去向”是高信息密度模块，但默认展示会让结果区显得很长；
- “市场情绪”“扫描快照”“热门方向”虽然已经在同一行，但内部还是偏竖向卡片，视觉上仍旧像堆模块；
- 页面没有结果展示偏好记忆，每次刷新后都要重新回到同样的视觉密度。

## 3. 方案选择

### 方案 A：浏览器本地记忆展示偏好

使用 `localStorage` 保存短线结果区的勾选状态。优点是实现轻、无需后端、符合“本机记住”的要求。缺点是不同设备之间不会同步。

### 方案 B：保存到后端配置

把展示偏好写进 Nacos 或数据库。优点是可多端同步；缺点是 UI 偏好不该进入全局配置链路，改动面更大，也不符合这次需求的轻量性。

### 方案 C：仅页面会话记忆

用内存或 `sessionStorage` 维持本次会话。优点是最轻；缺点是刷新后丢失，不符合“记住”的要求。

采用方案 A。

## 4. 展示偏好模型

### 4.1 维度

结果区使用 5 个开关：

- `methodologyVisible`：方法
- `marketSentimentVisible`：市场情绪
- `fundFlowVisible`：今日资金去向
- `snapshotVisible`：扫描快照
- `hotDirectionsVisible`：热门方向

### 4.2 默认值

首次进入或本地数据损坏时，默认值如下：

- `methodologyVisible = false`
- `fundFlowVisible = false`
- `marketSentimentVisible = true`
- `snapshotVisible = true`
- `hotDirectionsVisible = true`

### 4.3 本地存储

使用一个版本化 key 保存偏好：

```text
ai-stock.short-term.result-view.v1
```

读取时只接受完整布尔值；如果 JSON 解析失败、字段缺失、`localStorage` 不可用或被浏览器阻止，直接回退到默认值。

保存时只写这 5 个布尔值，不写扫描结果、不写股票数据、不写时间戳。

## 5. 页面布局

### 5.1 结果区结构

扫描完成后，在结果摘要上方或紧接其后增加一条“结果视图”控制条，包含 5 个勾选项。控制条只在 `report` 可用时显示。

控制条下方分两层：

- 第一层：市场情绪、扫描快照、热门方向三张横版摘要卡；
- 第二层：按勾选显示的方法和今日资金去向辅助卡。

### 5.2 横版摘要卡

“市场情绪”“扫描快照”“热门方向”都改成横版摘要，不再做大段竖向说明。

要求：

- 在桌面端三张卡保持同一行；
- 每张卡内部采用横向信息带，突出 1-2 个核心指标；
- 说明文字压缩为短句或短标签，不再占用长段落；
- 在移动端自然堆叠，但卡片内部仍保持紧凑横排信息。

### 5.3 方法模块

“方法”默认隐藏。展开时放在结果区的辅助信息层，以短句列表或要点形式展示，不进入主视觉中心。

### 5.4 今日资金去向模块

“今日资金去向”默认隐藏。展开时展示为结构更紧凑的资金流摘要卡，优先保留：

- 数据日；
- 覆盖情况；
- 主力流入 / 流出概览；
- 数据缺口提示。

## 6. 文件边界

预计修改以下文件：

- `apps/web-react/src/pages/ShortTermPage.tsx`
- `apps/web-react/src/pages/ShortTermPage.test.tsx`
- `apps/web-react/src/lib/shortTermViewPreferences.ts`

其中：

- `ShortTermPage.tsx` 负责结果区布局、开关渲染和模块显隐；
- `shortTermViewPreferences.ts` 负责版本化本地偏好读写；
- `ShortTermPage.test.tsx` 负责默认值、切换、持久化和隐藏/展示行为测试。

## 7. 测试

### 7.1 页面行为测试

- 首次渲染时，“方法”和“今日资金去向”默认不显示；
- “市场情绪”“扫描快照”“热门方向”默认显示；
- 勾选某一项后，对应模块立即出现或消失；
- 刷新/重挂载后，勾选状态保留；
- 本地存储为空或损坏时，页面仍按默认值恢复；
- 未拿到 `report` 时，不显示结果视图控制条。

### 7.2 结构测试

- 桌面端结果区包含三张横版摘要卡；
- “热门方向”不再以长竖列作为默认形态；
- “今日资金去向”默认不占首屏空间；
- 布局在移动端仍可正常堆叠和滚动。

### 7.3 回归验证

- 不影响短线扫描发起与轮询；
- 不影响候选详情、买入录入、交易复盘入口；
- 不改任何后端数据结构和接口。
