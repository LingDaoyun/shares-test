# 全市场行情备用路径修复计划

**Goal:** 东方财富连接提前关闭时，短线右侧扫描能使用完整备用行情，并继续报告覆盖率及交易时间。

**Architecture:** 保留东方财富现有分页流程；它无法返回行情时，从新浪 `hs_a` 列表按证券代码排序取得股票清单，再复用腾讯批量行情。清单抓取前后校验总数，去重并排除清单外返回；完整性仍由实际覆盖数量判定。腾讯补齐其原始市值和量比字段。新浪申万证券Ⅱ `sw2_490100` 完整清单补上券商行业标记，保证原排除规则有效；清单不完整则报错。

**Tech Stack:** Java 17、Spring RestClient、Jackson、JUnit 5、MockRestServiceServer。

## Constraints

- 用户已批准上述方案及定向测试、更新当前后端、复现扫描。
- 保留工作区已有改动，沿用当前分支，不提交混合改动。
- 不修改选股规则，不用抓取时间填补交易时间，不把缺失行情视为完整覆盖。
- 仅更新 API；保留当前镜像和 JAR，以便回滚。
