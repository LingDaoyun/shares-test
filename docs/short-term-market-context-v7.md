# 短线候选：大盘环境与执行约束 v7

版本：`short-term-research-v7-market-context`。历史 v6 报告保留原始结果；新增市场字段缺失时展示未知，不反推过去的量能。新旧版本分别验证。

个股仍按趋势25%、相对强弱20%、形态35%、量价20%计算研究分。大盘环境独立约束动作和仓位，不能靠个股高分抵消。

## 数据口径

- 上涨广度、收益中位数、涨跌幅波动和上涨侧成交额来自点时全A股有效报价。成交额覆盖不足95%时，不用少数报价推断资金参与度。
- 样本成交额仅汇总沪深A股（代码0/3/6开头），非负金额有效覆盖至少95%；真实0保留，缺失不填0。
- 两市量额比较使用东方财富上证指数 `1.000001` 与深证综指 `0.399106` 两日分钟数据。每分钟成交额（元）、成交量（手）分别求和，不互相替代。
- 必须验证前一交易日。两市两日均需从09:30覆盖至同一完整分钟，午休除外；盘中不纳入当前未完成分钟。缺分钟、冲突重复、负值、基期0和不可核实日期均不生成变化率。
- 报价样本截止时间与指数比较时刻分别展示。15:01后且具有15:00完整数据才标记收盘比较；历史快照只能复盘，不能执行。
- 涨停池仅在交易日匹配、取得时间不晚于决策时间且不超过3分钟时用于实测计数；否则使用明确标注的涨跌幅近似。炸板率缺失即未知；跌停接口失败不能解释为实测0家。
- 涨停看板旧日线量能在盘中不再与昨日全天比较，改为“盘中暂不可比”；历史日比较不读取未来日期。

## 当前初始规则

先保留原有市场广度、资金参与度、跌停扩散及拥挤波动判断，再应用以下约束：

| 条件 | 最终上限 |
| --- | --- |
| 行情覆盖不足或系统性退潮 | 暂停新仓 |
| 同刻成交额增加至少10%，上涨广度不超过35%，涨跌幅中位数不高于-0.8% | 暂停新仓（放量下跌） |
| 同刻成交额或成交量下降至少15% | 仅轻仓 |
| 实测涨停与炸板合计至少10家，炸板率至少45% | 仅轻仓 |
| 量额比较不可用 | 仅轻仓，不推断缩量 |
| 原有修复或拥挤高波动 | 仅轻仓 |

轻仓使单只计划上限不超过短线资金的20%，已有更低上限不放宽。T+2保留比例仍以原计划仓位为分母。所有可执行结果还必须通过原有14:45–14:49入场窗口、形态、财报、分时、价格与费用后风险收益门槛。

尾盘检查最多4个并发任务，所有候选完成后统一检查计划有效期、市场约束，再排序和截取。暂停执行或过期计划同步将建议改为等待。所有形态分支要求日线更新到已核实的最近完整交易日，旧日线不能借新报价获得执行资格。

这些阈值是可检验的初始研究参数，不是收益结论。后续按版本、市场状态、形态分别跟踪T+1/T+2，评估交易成本、回撤、样本量及样本外表现后再调整。
