# 实施路线

## 第 1 阶段：MVP 底座

目标：跑通从规则配置到观察池的闭环。

- 公司、政策主题、规则、观察池 API。
- Java 规则引擎，支持阈值条件、权重、版本递增。
- Vue 控制台，支持查看规则并对公司样本试算。
- PostgreSQL/pgvector、Redis、MinIO 基础设施脚本。

## 第 2 阶段：数据采集与文档库

目标：把示例数据替换成真实资料。

- 已完成：腾讯 A 股行情、东方财富行情备用源、年报关键指标、中国政府网最新政策在线接入。
- 已完成：巨潮公告证据查询骨架，支持真实公告样本和公司画像降级摘要。
- 已完成：公告 PDF 轻量正文解析，支持抽取风险事件、壁垒线索和兑现线索。
- 交易所公告源扩展与证券内部编码映射补齐。
- 年报 PDF 入 MinIO。
- 文档解析、切片、全文索引。
- 公告与公司、主题、风险事件关联。

## 第 3 阶段：AI Workflow

目标：让 AI 做结构化抽取，而不是自由荐股。

- 已完成：政策/产业报告趋势分析 Prompt 契约与预览接口。
- 已完成：公司研究视图，统一输出五维评分、证据强度、数据缺口和观察阶段。
- 政策主题抽取。
- 产业链环节拆解。
- 公司主营与主题相关度判断。
- 已完成：公告标题层面的壁垒、风险、兑现线索抽取。
- 已完成：公告 PDF 正文级标题/正文混合事件抽取。
- 已完成：确定性多 Agent 投研委员会，支持政策、财务、壁垒、估值、风控五角色共识。
- 公告 PDF 全文级 AI 事件抽取与人工复核队列。
- 所有 AI 输出写入证据表，并保留 prompt、模型、输入、输出和来源。

## 第 4 阶段：回测与规则发布

目标：每次规则调整都能先看历史效果。

- 规则版本表落库。
- 规则发布审批流。
- 规则回测预览。
- 当前股票池试跑。
- 发布后通过 Redis/Nacos 通知服务热加载。

## 第 5 阶段：AgentScope Java 增强

目标：做开放式深度研究，而不是替代规则引擎。

- 新增 `ai-agent-service`。
- 将当前确定性 Agent 升级为 AgentScope Java/LLM 协作 Agent。
- 政策 Agent、财务 Agent、风险 Agent、估值 Agent、反方 Agent 多角色协作。
- Agent 输出研究报告和证据摘要。
- 最终评分仍由 `rule-engine-service` 完成。
