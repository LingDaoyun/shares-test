## 行为

默认页面使用 `five-day-context-v2`；可切换 `five-day-observation-v1` 纯量价对照。API 未提供 strategy 时继续使用 v1。两版本快照、情景历史及规则统计隔离。

v2 先检查市场风险、行业 3/5 日相对强度及上涨/放量参与，再复核原量价资金规则。100 只复核名额在持续强行业间轮询，避免全市场窄幅排序排除热点行业。个股还须确认转强，并完成最近 7 日公告标题审阅。规则不为农业或其他指定行业加分；没有条件齐备股票是有效研究结果。所有阈值仍为研究初值，尚未验证盈利优势。

政策保存来源链接、原始公开时间精度和实际取得时间；JSON 时间不再截成日期。公司公告缺失原始证券身份、标题或 ID 时，整次获取视为不可确认。同一链接出现不同标题不能吞掉风险线索。政策只提供行业关联，公告只审阅标题；不声称覆盖全网消息、传闻或已读全文。

入场前检查与冻结信号分离，核验前瞻资格、唯一入场日、连续竞价时段、当前报价时间、市场覆盖、开盘/现价边界、价格基准及最新公告。检查本身不下单或写成交。持有期仍从真实首次买入日算第 1 天，第 5 个交易日为计划退出日；日期不是实际卖出证明。
